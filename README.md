# Iron Go

Iron Go is a lightweight Go IDE for **macOS 15 and later**. Edit and navigate Go code in Monaco, run and debug with the local Go toolchain, and work in existing Go modules and workspaces.

## Get started

- [Build and launch Iron Go](docs/BUILDING.md#run-from-source) from this repository.
- [Use the workbench](docs/USAGE.md): open a project, navigate, edit and save, run tests, and debug.
- [Look up keyboard shortcuts](docs/USAGE.md#keyboard-shortcuts), including Back and Forward.

## Work on Iron Go

Start with the [documentation index](docs/README.md) for the architecture,
contribution rules, testing guide, build and release steps, and design records.
